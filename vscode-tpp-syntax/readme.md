# Instalação da Extensão TPP

Para instalar a extensão de suporte à linguagem TPP no Visual Studio Code, siga os passos abaixo.

1. Abra o projeto da extensão no Visual Studio Code.
2. Pressione `Ctrl + Shift + P`.
3. Procure por **Developer: Install Extension from Location...**.
4. Selecione a pasta que contém o arquivo `package.json`.
5. Reinicie o Visual Studio Code.

Após a instalação, arquivos com a extensão `.tpp` deverão ser reconhecidos automaticamente como arquivos da linguagem TPP.

Caso isso não ocorra, basta selecionar **TPP** manualmente no seletor de linguagem localizado no canto inferior direito do Visual Studio Code.
